# Audio provenance and rights

The WAV files in this directory are derived from *The Legend of Zelda: Ocarina
of Time* (Nintendo). Nintendo retains all rights to the underlying character
audio, including Navi's voice clips. No ownership of those clips is claimed.

The repository's MIT license covers source code and configuration only. It
does not cover these recordings or grant rights to Nintendo's audio.

The original repository included these clips for personal, non-commercial use.
This update preserves the same five recordings without modification. This
notice records their provenance; it is not a license from Nintendo.

| File | Clip | Format |
|---|---|---|
| `hello.wav` | Hello! | 16-bit mono PCM WAV, 32 kHz |
| `hey.wav` | Hey! | 16-bit mono PCM WAV, 32 kHz |
| `listen.wav` | Listen! | 16-bit mono PCM WAV, 32 kHz |
| `look.wav` | Look! | 16-bit mono PCM WAV, 32 kHz |
| `watchout.wav` | Watch out! | 16-bit mono PCM WAV, 32 kHz |

Use the user audio directory setting to supply your own replacement recordings
without editing installed plugin files.
