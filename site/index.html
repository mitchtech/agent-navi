CHOOSE YOUR COMPANION

Your setup. Your choice.

Each component works on its own. Installing the pet never enables sounds.

Sounds for your agent

Node.js 22+ and a local audio player are required. Restart your agent after installation.

CLAUDE CODE

/plugin marketplace add mitchtech/agent-navi
/plugin install navi@agent-navi

CODEX

codex plugin marketplace add mitchtech/agent-navi
codex plugin add navi@agent-navi

GEMINI CLI

gemini extensions install https://github.com/mitchtech/agent-navi --ref v__VERSION__

Review and trust the sound hooks in Codex’s hook settings. Other agents use the standalone event interface.

A pet, without the setup

Download pet ZIP ↓

Extract the navi folder into ~/.codex/pets/, or the pets folder inside your configured CODEX_HOME. No Node.js is needed for the ZIP.

Refresh the desktop pet picker and choose Navi, or enter /pets Navi in a supported Codex CLI terminal. Your current pet stays selected until you choose otherwise.

Creating a web pet? Download the web atlas for a separate account upload. Upload and attribution guide

Prefer the command line?
npm install -g github:mitchtech/agent-navi#v__VERSION__
agent-navi pet install
agent-navi doctor --pet

These commands install pet files only. Use agent-navi pet uninstall to remove an unchanged CLI-managed installation.

Sound controls
agent-navi status
agent-navi mute prompt_submitted
agent-navi preset attention
agent-navi unmute all

Use the bundled Navi control skill in your agent, or the standalone CLI. Global mute preserves your event preferences.
