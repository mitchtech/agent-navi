# Original Navi pet

The manifest and atlas here preserve the original local files supplied by
Michael J. Mitchell. Do not recompress or edit them. Their SHA-256 values are
recorded in NOTICE.md and validated by scripts/check-pet.py.

The active installation bundle lives in pets/navi. This archive is kept in Git
and excluded from runtime packages. The contributor artwork license and
original provenance notice are preserved alongside the two host files.
