# Demo video

`demo.mp4` is a 36-second recording of a real Claude Code session with Agent
Navi loaded, captured with VHS. Captions and the end card were added afterward.
The Navi clips on its soundtrack were placed at the moments their hook events
fired. `demo-poster.jpg` is a frame from the same recording.

The Navi voice clips are Nintendo's; see the [audio rights notice](../../audio/NOTICE.md).
